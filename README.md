# DiskSpace AI for Homebrew

[DiskSpace AI](https://diskspaceai.com) is a Mac disk cleaner that explains what each folder is and only pre-selects what recreates itself. Signed and notarized by Apple.

```sh
brew install --cask diskspaceai/tap/diskspace-ai
```

This installs the app in Applications and links the `diskspace` command (CLI and MCP server for Claude Code, Codex and other agents). The app updates itself; `brew upgrade` works too.

- Website: https://diskspaceai.com
- Docs, folder rules and MCP setup: https://github.com/diskspaceai/diskspace-ai
